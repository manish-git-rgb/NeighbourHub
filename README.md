# NeighborHub

NeighborHub is a hyperlocal community platform for discovering nearby posts, events, services, places, recommendations, and local issues.

## Repository structure

- `apps/frontend` - Next.js frontend
- `apps/backend` - FastAPI backend
- `workers` - background workers
- `packages/shared` - shared logic and types
- `infra` - infrastructure and deployment files
- `docs` - product, architecture, and API documentation

## Getting started

1. Set up the backend environment in `apps/backend`
2. Set up the frontend environment in `apps/frontend`
3. Configure environment variables in `.env`
4. Run Docker Compose for local services
